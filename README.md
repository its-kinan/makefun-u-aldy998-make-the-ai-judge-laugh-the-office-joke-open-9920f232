One original one-line joke about office life: the office printer runs out of paper and responds by printing a 40-page error report explaining, in great detail, that it is out of paper. A deterministic program writes the line to `/output/entry.txt` — no network, no randomness, no timestamps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
